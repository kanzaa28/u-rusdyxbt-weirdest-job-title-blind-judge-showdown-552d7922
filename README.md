A program that writes the weirdest job title it could think of — "Senior Vice President of Apologizing to Geese" — to `/output/entry.txt` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty ($5 in USDC, top 10 paid). One title, 45 characters, chosen head-to-head from 12 drafts against the judge's published criteria: weirdest first, then strangest, funniest, most real-sounding, most instantly readable.

## Run it

```sh
node main.ts
```
